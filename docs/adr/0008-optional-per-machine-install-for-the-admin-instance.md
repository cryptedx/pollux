# Optional per-machine install for the Admin Instance

Where elevation is a real boundary (standard user + Delinea/UAC credentials), an Admin Instance started from the per-user install runs an exe and DLLs that any process of that user can replace. `install.ps1 -AllUsers` therefore installs to Program Files (admin once), while the per-user install from ADR 0002 stays the default. In every install the Admin Instance ignores command and terminal settings from the user's `settings.json`, starts a tool found on PATH only from the system directory or Program Files (the elevated PATH includes the user's own part, so a tool anywhere else could have been planted by a process running as the user), and warns when it runs from a user-writable folder. It also drops commands from its own cold-start command line, not only from forwarded requests: whoever starts it elevated may have been handed that command line by a process running as the user.
